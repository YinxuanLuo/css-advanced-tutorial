第 03 章 · Flexbox 实战模式与坑

下面每个面板对应正文的一个实战模式或一个坑。红框/红块通常是反例（❌），绿框/绿块是正例（✅）。

① 导航栏：logo 左 + 菜单右（margin-left: auto）

不给容器设 justify-content，只给菜单加 margin-left: auto，它就被推到右边。

② 导航栏变体：搜索框吃满中间（flex: 1 + min-width: 0）

logo 固定、搜索框 flex: 1 撑满中间、按钮固定。输入超长内容试试，搜索框不会被撑爆。

搜索框是 flex item，默认 min-width: auto 会被长内容撑爆、挤出按钮。这里加了 min-width: 0 才允许它收缩。

这是 Flex"一维本质"的必然：它没法让最后一行孤卡保持和其他行一致的宽度。Grid 的 repeat(auto-fill, minmax(120px, 1fr)) 天然规避。

⑤ 圣杯布局：header + 三列 + footer

外层 column 撑起纵向结构，内层 row 撑起三列。两侧固定、中间 flex: 1 自适应。

核心：.body { display: flex; flex: 1 } 吃掉中间高度；.main { flex: 1 }（basis 0%）吃掉中间宽度。中间列用 flex: 1 而非 flex: auto，防止内容把它撑大。
